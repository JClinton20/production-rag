# production-rag

## Setup

### Clone Repo
```bash 
git clone https://github.com/JClinton20/production-rag
```

```bash
cd production-rag 
```

### Create environment

```bash
python -m venv venv 
```

### Activate environment

Linux/macOS:
```bash
source venv/bin/activate
```

Windows:
```bash
.\venv\Scripts\activate 
```

### Install requirements

```bash
pip install -r requirements.txt 
```
